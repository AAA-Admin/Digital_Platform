🎨 1. GOLD GRADIENT SYSTEM (RECREATABLE)
🟡 A. High-Gloss Gold (Logo “A”)

This is the metallic, reflective version with strong light simulation.

✅ Gradient Type:
Linear Gradient
Angle: ~110° to 120°
🎯 Gradient Stops (Base Setup):
0%   → #6B4E16   (deep shadow gold)
20%  → #A67C2E   (rich base gold)
40%  → #FFD76A   (bright highlight)
55%  → #FFF3B0   (specular peak / shine)
70%  → #D4A73B   (return to mid gold)
100% → #5A3F0F   (dark edge shadow)
📞 How you'd describe it:

“It’s a multi-stop metallic gradient with a tight highlight band, creating that reflective gold effect.”

White → Transparent
Opacity: 10–20%
Blend mode: Overlay / Soft Light

👉 This simulates light hitting the surface
